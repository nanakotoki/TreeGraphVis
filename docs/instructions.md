# 教学级全量树与图算法可视化平台 — AI Agent 开发规范与执行指南 (v1.0)

## 1. 项目定位与核心设计铁律 (Core Mandates)

本项目旨在构建一款**面向高校课堂演示、算法竞赛教学与开发者深度学习的树（Tree）与图（Graph）算法交互式可视化系统**。系统包含 **75+ 种常见及进阶树/图算法**，通过“统一拓扑指令流协议（Topology Trace Protocol）”实现算法逻辑与矢量动画引擎的彻底解耦。

### 1.1 视觉清晰度铁律（严禁像素块/粗糙网格化）
* **禁止像素块充当图拓扑**：严禁使用粗糙的二维网格色块（Pixel Grid / Table Cell）代替图节点与边（仅在演示 A* 几何地图寻路的子模式中允许开启网格背景，且必须叠加矢量箭头与数值浮层）。
* **100% 矢量抗锯齿渲染**：画布必须基于高 DPI 矢量图元渲染（Web 端采用 SVG + HTML5 Canvas HiDPI 混合渲染；桌面端 PySide6 采用开启 `Antialiasing` 与 `SmoothPixmapTransform` 的 `QGraphicsView/QGraphicsScene`）。
* **拒绝瞬间闪烁，强制因果过渡**：
  * 任何边遍历/松弛（Relaxation）操作，必须渲染**从起点 $u$ 沿边滑向终点 $v$ 的高光脉冲粒子/渐变进度条**，让学生看清探索方向。
  * 任何树结构形态改变（AVL/红黑树/Splay 旋转、B 树分裂合并、堆上浮下沉、并查集路径压缩），必须采用 **300ms~600ms 缓动插值（Ease-In-Out Cubic）** 平滑过渡节点坐标，并在移动前用**彩色虚线**预示指针断连与重连目标。
* **防重叠几何避让**：
  * 存在双向有向边 $(u \to v)$ 与 $(v \to u)$ 或多重边时，必须自动计算法向偏移，渲染为**对称二阶贝塞尔曲线（Quadratic Bezier Arc）**，严禁边线与权重标签互相覆盖。
  * 边权重/容量标签必须带有圆角胶囊底色框（Pill Badge），悬浮于边线弧顶正中。

## 2. 教学级“四位一体”交互工作台架构 (4-Pane Pedagogical Workbench)

界面采用高对比度、无视觉干扰的四区域联动布局，所有区域由同一时间轴步进器（Time-Travel Stepper）同步驱动：

### 2.1 主矢量拓扑画布区 (Main Vector Topology Canvas - 占比 60%)
* **多维矢量胶囊节点 (Multi-Zone Node Anatomy)**：
  * **中心主核**：显示节点 ID 或键值 Key（支持圆形单键节点，以及 B 树/2-3-4 树/线段树的圆角矩形多槽位节点 `[Key1 | Key2 | Key3]`）。
  * **顶部动态角标 (Top Metric Badge)**：实时浮现算法核心状态，例如 Dijkstra 的 `d=7`、A* 的 `f=9 (g=4, h=5)`、AVL 树的 `BF=+2`、Tarjan 的 `dfn=3, low=1`、Kahn 拓扑排序的 `in=2`、线段树的区间范围 `[1..8]`、懒标记 `lazy=+5`。
  * **外部状态光环 (Outer Halo)**：结合色彩与描边样式（兼顾色盲友好）区分 6 种标准状态：`Default（默认未访问）`、`Active（当前焦点游标，带呼吸脉冲光圈）`、`Frontier（在队列/优先队列/栈中待处理）`、`Visited/Settled（已永久确定最优解）`、`Path/Result（最终入选最短路/生成树/匹配集）`、`Conflict/Error（负权环/奇环冲突/失衡告警，红色闪烁）`。
* **智能自动布局引擎 (Auto-Layout Engines)**：
  * **分层紧凑树布局 (Reingold-Tilford Algorithm)**：所有树算法默认启用，保证父节点严格位于子节点几何中心上方，同层深度水平对齐，左右子树通过轮廓线（Contour）计算紧凑间距且绝不交叉。
  * **力导向图布局 (Force-Directed / Kamada-Kawai)**：无向图、连通性、一般图匹配默认启用。
  * **层次化有向图布局 (Sugiyama Layered DAG Layout)**：拓扑排序、关键路径 AOE 网、Dinic 网络流分层图默认启用，严格按层级从左到右或从上到下排列。
  * **双列二分图布局 (Bipartite Two-Column Layout)**：匈牙利算法、KM 算法、稳定婚姻默认启用，左部与右部垂直对齐。
  * **圆环布局 (Circular Layout)**：Floyd 全源最短路、稠密图、欧拉回路可选启用。
* **画布交互控制**：无级缩放（Zoom）、拖拽平移（Pan）、手动拖拽节点固定位置（Pin Node）、一键重新布局、常驻色标图例（Legend）。

### 2.2 辅助数据结构同步透视窗 (Auxiliary Structure Inspector - 右上侧，占比 20%)
树与图算法的核心逻辑往往隐藏在辅助结构中。本面板根据当前运行的算法**自动挂载对应的可视化子组件**：
* **线性容器视图**：BFS 先进先出队列管道、0-1 BFS 双端队列（两端进出动画）、DFS/Tarjan 显式调用栈帧（显示当前局部变量与返回地址）、优先队列最小堆列表（按距离/权值动态重排）。
* **状态追踪表格 (State Watch Table)**：多列高亮表格，实时展示每个节点的 `dist[u]`、`parent[u]`、`dfn[u]`、`low[u]`、`inDegree[u]`、`color[u]`，刚刚被修改的单元格触发黄色高亮闪烁。
* **并查集森林副视图 (DSU Sub-View)**：在运行 Kruskal、Tarjan 离线 LCA、连通分量算法时，同屏小窗口实时展示并查集的树形认父结构与路径压缩过程。
* **二维矩阵热力视图 (2D Matrix Inspector)**：在运行 Floyd-Warshall、传递闭包、邻接矩阵转换时，实时展示 $N \times N$ 矩阵，高亮当前比较的 $(i, k) + (k, j) \to (i, j)$ 三个单元格。
* **底层紧凑数组映射带 (Array Strip View)**：在运行二叉堆、线段树、树状数组（Fenwick Tree）、树链剖分（DFS 序连续区间）时，画布底部同步展示一维连续数组下标及对应关系。
* **残量网络对照窗 (Residual Graph Split-View)**：在运行最大流/费用流时，支持“原图流量/容量视图 (`flow/cap`)”与“残量网络正反向剩余容量视图”一键同屏并排对照或图层叠加切换。

### 2.3 伪代码行级追踪与变量监视区 (Pseudocode & Variable Tracker - 右下侧，占比 20%)
* 展示当前算法的结构化教学伪代码（及对应的 C++ / Python / Java 实现切换标签）。
* 每执行一步微指令，**同步高亮当前正在执行的代码行**，并在代码行右侧以内联气泡（Inline Inlay Hints）展示当前变量实参（如 `u = 'B', v = 'D', w = 4, dist[v] = 12 -> 9`）。

### 2.4 自然语言教学解说栏与时光机控制条 (Narrator Banner & VCR Bar - 底部常驻)
* **分步教学解说横幅 (Step Narrator)**：用通俗、严谨的中文教学语言解释**当前步骤的因果逻辑**（例如：*“步骤 14：节点 C 的平衡因子 BF = +2（左子树高 2，右子树高 0），且左孩子 B 的 BF = -1，判定为 LR 型失衡。第一步：先对左孩子 B 执行左旋（Left Rotate）将其转化为 LL 型。”*）。
* **VCR 全向时光机控制**：
  * `|<` 重置到初始状态
  * `<` **单步后退（Step Backward，核心教学刚需！讲课随时回退重看）**
  * `Play / Pause` 自动播放与暂停
  * `>` 单步前进（Step Forward）
  * `>|` 跳至算法结束
  * **关键帧书签轴 (Timeline Scrubber with Milestones)**：进度条上自动标记关键事件锚点（如“第 1 次旋转”、“发现负环”、“第 3 条增广路”），支持点击锚点秒跳。
  * **倍速与粒度切换**：支持 `0.25x ~ 8x` 无级调速，以及**“教学细粒度模式（展示每次比较与指针移动）”**与**“宏观步进模式（每次跳跃一个完整阶段/外层循环）”**一键切换。

## 3. 全量树与图算法全景实现清单 (Exhaustive Algorithm Catalog)

请 Agent 严格按以下 **2 大卷、15 个专题分类、共 78 个算法/数据操作** 构建模块化算法库。每个算法必须独立封装并输出标准的 `TopologyTrace` 指令流。

### 第一卷：树结构与树算法全集 (Trees & Hierarchical Structures)

#### 专题 T1：二叉树与多叉树遍历 (Tree Traversals)
1. **二叉树先序遍历 (Pre-order Traversal)**：递归版（同步展示调用栈帧）与迭代版（显式栈）。
2. **二叉树中序遍历 (In-order Traversal)**：递归版与迭代版（展示一路向左压栈与弹出访问过程）。
3. **二叉树后序遍历 (Post-order Traversal)**：递归版、双栈迭代版、以及 `prev` 指针单栈迭代版。
4. **二叉树层序遍历 (Level-order / BFS)**：同步展示 FIFO 队列进出与按层波纹高亮。
5. **锯齿形/之字形层序遍历 (Zigzag Level-order)**：双端队列或奇偶层方向翻转箭头演示。
6. **Morris 线索化遍历 (Morris Pre/In/Post-order)**：$O(1)$ 空间遍历，**重点用彩色虚线弧可视化临时前驱线索指针（Thread Pointer）的建立与第二次访问时的拆除过程**。
7. **N 叉树遍历 (N-ary Tree Pre/Post/Level-order)**：多子节点扇形展开与遍历。

#### 专题 T2：二叉搜索树与自平衡搜索树 (BST & Self-Balancing BSTs)
8. **标准二叉搜索树 (Binary Search Tree - BST)**：
   * 查找（Search 比较路径高亮）
   * 插入（Insert 向下寻位与新叶挂载）
   * 删除（Delete 完整覆盖 3 种情况：叶子直接删、单孩子子承父业、**双孩子寻找中序后继/前驱高亮替换并转删后继**）。
9. **AVL 平衡二叉树 (AVL Tree)**：
   * 节点顶部实时显示高度 `h` 与平衡因子 `BF = h(L) - h(R)`。
   * 完整可视化四种旋转修复：**LL 右旋**、**RR 左旋**、**LR 先左后右双旋**、**RL 先右后左双旋**，以及删除节点后沿父链向上回溯的多次旋转修复。
10. **红黑树 (Red-Black Tree)**：
    * 可切换显示/隐藏底部黑色 `NIL` 哨兵叶子节点；实时校验每条路径的黑高（Black Height）。
    * **插入修复 (Insert Fixup)**：清晰演示双红冲突下 **叔节点为红（变色上溢）**、**叔节点为黑且折线（旋转转共线）**、**叔节点为黑且共线（旋转+变色终止）** 全部 Case。
    * **删除修复 (Delete Fixup)**：用特殊“双重黑（Double Black）”光圈标记失衡点，完整演示 **兄弟为红（转为兄黑）**、**兄弟为黑且双侄皆黑**、**兄弟为黑且近侄红远侄黑**、**兄弟为黑且远侄红** 四种经典 Case。
11. **伸展树 (Splay Tree)**：
    * 演示局部性原理与每次操作后的根伸展（Splaying）：**Zig（单旋）**、**Zig-Zig（同向双旋，先转父再转己）**、**Zig-Zag（异向双旋，连转两次自己）** 的对比动画。
12. **替罪羊树 (Scapegoat Tree)**：
    * 节点显示子树大小 `size`；当违反 $\alpha$-权重平衡因子时，高亮失衡替罪羊子树，**演示将其“拍平（Flatten）”为底部有序数组/链表，再递归取中点重构为完美平衡二叉树的动画**。
13. **树堆 (Treap - 旋转版 & 无旋 FHQ-Treap)**：
    * 每个节点显示双属性 `[Key | Priority]`。
    * **旋转 Treap**：BST 插入后按随机优先级旋转维护堆性质。
    * **FHQ-Treap（非旋转 Treap）**：**可视化按值/按大小分裂 `Split(T, k -> L, R)` 拆断指针的过程，以及按优先级递归合并 `Merge(L, R)` 的拉链式缝合动画**。
14. **笛卡尔树 (Cartesian Tree)**：
    * 顶部展示原数组（下标满足 BST，值满足堆），右侧同步展示**单调栈维护右链（Right Spine）**的 $O(n)$ 建树过程。

#### 专题 T3：多路平衡搜索树与存储索引树 (Multi-Way Search & Index Trees)
15. **2-3 树 & 2-3-4 树 (2-3 / 2-3-4 Trees)**：
    * 演示 2-节点、3-节点、4-节点内部键槽扩展，以及“自底向上分裂（2-3 树）”与“自顶向下预分裂（Top-down 2-3-4 树）”的对比。
16. **B 树 (B-Tree，阶数 $M$ 支持 3~7 动态配置)**：
    * 多槽位胶囊节点 `[k1 | k2 | k3]` 与子指针插槽渲染。
    * **插入上溢分裂 (Split)**：满节点高亮，中间键向上弹出融入父节点，左右半区裂变为两个独立节点。
    * **删除下溢修复 (Underflow)**：演示向左右够富余的兄弟节点“借键旋转（通过父节点中转）”以及兄弟不够借时的“父键下沉合并（Merge）”。
17. **B+ 树 (B+ Tree)**：
    * 严格区分**内部路由索引节点（浅色）**与**底部全量数据叶子节点（深色）**。
    * **底部渲染水平双向有序链表箭头带**，支持演示单点查询与 **`Range Query [L, R]` 范围查询（先树形下潜定位 `L`，再沿底部叶子链表横向滑行扫描至 `R`）**。
18. **B* 树 (B* Tree)**：演示满节点优先向兄弟节点转移键（丰满度达到 $2/3$），双满时执行 `2-to-3` 分裂的过程。

#### 专题 T4：堆与优先队列树族 (Heaps & Priority Queue Trees)
19. **二叉堆 (Binary Min/Max Heap)**：
    * **强制采用“上层完全二叉树拓扑 + 下层紧凑数组条”双视图联动**，高亮父子下标映射公式 `parent = (i-1)/2, left = 2i+1, right = 2i+2`。
    * 包含插入上浮（`Sift-Up`）、弹出堆顶下沉（`Sift-Down`）、以及 $O(n)$ 自底向上 **Floyd 建堆** 与 $O(n \log n)$ 逐个插入建堆的步数对比。
20. **左偏树 (Leftist Tree / 可并堆)**：节点角标显示外节点距离 $dist$，演示沿右链递归合并及违背左偏性质（$dist(L) < dist(R)$）时交换左右子树的动画。
21. **斜堆 (Skew Heap)**：演示无条件递归合并并在回溯时翻转所有经过节点左右子树的动画。
22. **二项堆 (Binomial Heap)**：展示二项树森林 $B_0, B_1, B_2 \dots$，可视化类似**二进制加法进位**的同阶二项树合并与 `extractMin` 拆根重并过程。
23. **斐波那契堆 (Fibonacci Heap)**：
    * 渲染根循环双向链表与 `min` 指针；演示惰性合并、`extractMin` 触发的 **`Consolidate` 度数桶数组（Degree Array）合并树森林过程**，以及 `decreaseKey` 触发的**级联切断（Cascading Cut）与 `mark` 标记位变色**。
24. **配对堆 (Pairing Heap)**：演示 `deleteMin` 时拆散孤儿森林的“从左往右两两配对（Pass 1）”与“从右往左累积合并（Pass 2）”两阶段动画。

#### 专题 T5：字符串树、前缀结构与自动机 (Trie & String Trees)
25. **标准字典树 / 前缀树 (Trie)**：支持插入、完全匹配、前缀匹配搜索，单词结尾节点带星标/双环高亮。
26. **压缩字典树 / 基数树 (Radix Tree / Patricia Trie)**：演示单分支链自动折叠为多字符边标签，以及插入新词在边中间分叉裂边的过程。
27. **0-1 异或字典树 (0-1 XOR Trie)**：底部展示整数二进制位展开，演示寻找最大异或对时**在每一层贪心尝试走相反比特位分支（0 找 1，1 找 0）**的决策路径。
28. **AC 自动机 (Aho-Corasick Automaton)**：
    * 第一阶段：构建基础 Trie 树。
    * 第二阶段：**通过 BFS 逐层构建失配指针 `fail`（用半透明彩色弧线渲染，支持悬停单个节点仅高亮其 `fail` 链以防视觉杂乱）**。
    * 第三阶段：底部输入主串文本，游标逐字符扫描并在 Trie 边与 `fail` 边之间动态跳转，同时收集所有匹配命中的模式串。
29. **后缀树 (Suffix Tree - Ukkonen 在线构建演示)**：可视化活动点三元组 `(active_node, active_edge, active_length)`、剩余后缀数 `remainder` 以及后缀链接（Suffix Link）虚线跳转。

#### 专题 T6：区间树、竞赛高阶树与空间划分树 (Interval, Competitive & Spatial Trees)
30. **哈夫曼树与编码 (Huffman Tree & Coding)**：
    * 右侧展示频率优先队列，主画布演示**每次弹出最小两棵树合并生成新父节点、森林逐渐长成一棵二叉树**的过程，完成后自动在左分支标 `0`、右分支标 `1` 并生成哈夫曼编码对照表。
31. **并查集森林 (Disjoint Set Union - DSU)**：
    * 对比演示朴素合并、**按秩/按大小合并（Union by Rank/Size）**，以及 `Find(x)` 时**路径压缩（Path Compression：沿途所有节点脱离原父节点，如折扇展开般直接挂载到根节点下方）**的震撼视觉效果。
    * 扩展支持**带权并查集（维护节点到根的距离/模数关系）**与**可撤销并查集（按栈回滚历史操作）**。
32. **线段树 (Segment Tree)**：
    * 每个节点显示管理区间 `[L, R]`、聚合值（Sum/Max/Min）及懒标记徽章 `Lazy`。
    * 演示递归建树、单点更新、区间查询（高亮被完全覆盖的拆分节点并跳过无关分支）。
    * **重点可视化懒标记下传（`PushDown`）**：当后续查询/修改需要深入带有 `Lazy` 标记的节点时，播放 `Lazy` 徽章分裂为两颗粒子滑向左右子节点的动画。
33. **可持久化线段树 / 主席树 (Persistent Segment Tree)**：
    * **支持多历史版本根节点并排展示**；每次单点修改生成新版本根时，**新建的 $\log n$ 个路径节点用高亮彩色渲染，而未修改分支直接绘制指向旧版本节点的跨树共享指针**，让“共用节点省空间”一目了然。
34. **树状数组 (Fenwick Tree / Binary Indexed Tree)**：
    * 同时展示 `lowbit(x) = x & -x` 的二进制位分解、**条形区间覆盖跨度图**，以及将数组下标连接为“更新树（Update Tree）”与“查询树（Query Tree）”的拓扑跳转路径。
35. **树链剖分 (Heavy-Light Decomposition - HLD)**：
    * 第一遍 DFS 标注 `size, depth, parent, heavy_son`；第二遍 DFS 优先走重儿子。
    * **画布中将重链（Heavy Chains）用加粗彩色实线包裹高亮，轻边用细虚线表示**，并在底部同步展示剖分后**重链在 DFS 序一维数组上映射为连续区间**的对应关系，演示树上路径查询如何拆解为若干段连续区间线段树查询。
36. **树上最近公共祖先算法族 (LCA - 4 种方法同台对比)**：
    * 朴素逐层向上跳法。
    * **倍增法 (Binary Lifting)**：右侧展示 $fa[u][k]$ 倍增表，画布上用跨层大弧线展示先将深度对齐、再按 $2^k$ 从大到小同步跳跃至 LCA 下一层的过程。
    * **Tarjan 离线 LCA**：结合 DFS 遍历染色（未访问白、访问中灰、已回溯黑）与并查集合并实时回答查询对。
    * **欧拉序转 RMQ 法**：底部展示长度为 $2n-1$ 的欧拉遍历序列与深度折线图，演示两节点首次出现位置区间内的最浅点即为 LCA。
37. **树的直径与重心 (Tree Diameter & Centroid)**：
    * 树的直径：对比“两次 DFS/BFS 端点搜索法”与“树形 DP 维护每个节点向下最长链 $d_1$ 与次长链 $d_2$”的过程。
    * 树的重心：实时计算并显示移除每个节点后剩余最大连通块的大小 $\max\_part[u]$，高亮使该值最小的1~2个重心节点。
38. **动态树 (Link-Cut Tree - LCT)**：
    * 区分实边（Preferred Edge，粗实线，由辅助 Splay 维护）与虚边（Path-Parent Edge，细虚线，认父不认子）。
    * 可视化核心操作 `Access(x)`（一路 Splay 到根并切换实虚边打通根到 $x$ 的实链）、`MakeRoot(x)`（打通后翻转区间标签）、`Link(x, y)` 与 `Cut(x, y)`。
39. **空间划分树：KD-Tree 与 四叉树 (QuadTree)**：
    * **双视图联动**：左侧为 2D 笛卡尔平面点集与垂直/水平分割超平面（KD-Tree）或象限递归网格（QuadTree），右侧为对应的树形拓扑结构，同步演示空间建树、矩形范围检索与最近邻搜索（KNN）的球体相交剪枝过程。

### 第二卷：图结构与图算法全集 (Graphs & Network Algorithms)

#### 专题 G1：图的多元表示与基础搜索 (Representations & Graph Search)
40. **图数据结构同步互转器 (Graph Representation Synchronizer)**：
    * 同屏联动展示同一张图的 **矢量拓扑图**、**邻接矩阵 (Adjacency Matrix)**、**邻接表链表视图 (Adjacency List)**、以及竞赛常用的 **链式前向星 (`head[], to[], next[], weight[]` 数组指针跳转视图)**。
41. **广度优先搜索 (BFS)**：队列联动、以源点为圆心的同心距离波纹层着色、标出 BFS 生成树边与非树边。
42. **深度优先搜索 (DFS & 边分类定理)**：
    * 节点标注进入与离开时间戳 `[d[u], f[u]]`，底部可选展示括号化定理区间条。
    * **强制将遍历过的每条边动态分类并着 4 种颜色**：**树边 (Tree Edge - 实线绿)**、**后向边 (Back Edge - 虚线红，指向祖先，预示有环)**、**前向边 (Forward Edge - 虚线蓝，指向子孙)**、**横叉边 (Cross Edge - 虚线橙，指向已回溯分支)**。
43. **双向广度优先搜索 (Bidirectional BFS)**：从起点 $S$（蓝波纹队列）与终点 $T$（橙波纹队列）交替扩展，当两股波纹在中间节点首次相遇时触发高光会师动画并回溯拼接最短路径。
44. **迭代加深搜索 (IDDFS)**：顶部显示当前深度截断阈值 `max_depth = 1, 2, 3...`，画布演示带深度标尺的受限 DFS 逐轮推进。

#### 专题 G2：最短路径算法族 (Shortest Path Algorithms)
45. **Dijkstra 单源最短路径算法**：
    * 支持切换朴素 $O(V^2)$ 扫描版与优先队列（最小堆）优化 $O(E \log V)$ 版。
    * 清晰演示：从优先队列弹出最小 `dist[u]` 节点 $\to$ 锁定为已确定集合 $S$ $\to$ 发射脉冲遍历所有出边 $(u, v, w)$ $\to$ 比较 `dist[u] + w < dist[v]` $\to$ 更新 `dist[v]` 与前驱树指针 `parent[v]`。
    * 内置**“含负权边导致贪心失效”的教学反例模式**，让学生直观看到为什么已锁定的节点后续无法被负权边正确更新。
46. **Bellman-Ford 算法**：
    * 顶部显示轮次仪表盘 `Iteration k / (V - 1)`，每轮按边集顺序扫描所有边执行松弛。
    * **第 $V$ 轮负权环检测**：若第 $V$ 轮仍有边可被松弛，自动沿前驱指针回溯定位**负权环（Negative Cycle）**，将该环路所有节点和边渲染为红色脉冲告警。
47. **SPFA 算法 (Queue-Optimized Bellman-Ford)**：
    * 同步展示 FIFO 队列与每个节点的在队标记 `inQueue[u]`、入队次数徽章 `cnt[u]`；当某节点 `cnt[u] >= V` 时触发负环告警。
48. **0-1 BFS (双端队列最短路)**：
    * 针对边权仅为 `0` 或 `1` 的图，右侧展示双端队列 Deque：**经过权 `0` 边松弛的节点从队首 `push_front` 插入（蓝色通道），经过权 `1` 边松弛的节点从队尾 `push_back` 插入（绿色通道）**。
49. **启发式搜索 A* 算法 (Topology & Euclidean Modes)**：
    * **重点提供“纯拓扑加权图模式”与“2D 几何坐标图模式”**（绝不仅是像素格子迷宫！）。
    * 每个节点顶部胶囊展示完整三元组 `f(n) = g(n) + h(n)`（实际起点代价 `g` + 启发式预估代价 `h`），右侧同步对比 **Open Set 最小堆** 与 **Closed Set 集合**，支持切换曼哈顿距离、欧氏距离、切比雪夫距离与零启发（退化为 Dijkstra）进行同图对比。
50. **Floyd-Warshall 多源最短路与传递闭包**：
    * **画布与右侧 $N \times N$ 距离矩阵 `D[][]`、前驱矩阵 `Path[][]` 深度联动**。
    * 外层循环锁定中转枢纽节点 $k$（用金色皇冠光环标记），对于每对 $(i, j)$，在画布上用虚线同时高亮两段路径 $i \leadsto k$ 与 $k \leadsto j$，对比直接距离 $D[i][j]$ 并更新矩阵热力值。
51. **Johnson 全源最短路算法 (稀疏图含负权)**：
    * 分四阶段清晰演示：① 引入超级源点 $q$ 向所有点连 0 权边 $\to$ ② 运行 Bellman-Ford 计算每个节点的高度势函数 $h(u)$ $\to$ ③ **播放边权转换公式动画 $w'(u,v) = w(u,v) + h(u) - h(v)$ 将所有边权变为非负** $\to$ ④ 以每个点为源跑 $V$ 轮堆优化 Dijkstra 并还原真实距离。
52. **次短路与第 K 短路 (2nd Shortest & Yen's / A* K-Shortest Paths)**：
    * 次短路：每个节点维护双距离槽位 `[dist1, dist2]`（最短与严格次短）同步松弛。
    * 第 K 短路：演示 Yen 算法在偏离点（Spur Node）临时屏蔽已选分支边重跑最短路并维护候选池的过程。
53. **差分约束系统可视化器 (System of Difference Constraints)**：
    * 左侧输入一组不等式 $x_v - x_u \le w$，**点击“转化为图”自动播放不等式变成有向加权边 $(u \xrightarrow{w} v)$ 的建图动画**，随后运行 SPFA 求出一组满足条件的变量特解或标出导致方程组无解的矛盾负环。

#### 专题 G3：最小生成树与生成树扩展 (Minimum Spanning Trees - MST)
54. **Prim 算法 (切分定理可视化)**：
    * **在画布上实时绘制一条包络已选点集 $S$ 与未选点集 $V \setminus S$ 的“割集分界虚线（Cut Boundary）”**，高亮所有横跨割集的候选横切边（Crossing Edges），每次挑出权重最小的一条加入生成树并扩张割集包络线。
55. **Kruskal 算法**：
    * 右侧展示按权重从小到大排序的边列表（Sorted Edge List），右下角同步挂载**并查集森林副视图**。
    * 逐条扫描边 $(u, v, w)$：若并查集中 $Find(u) \neq Find(v)$，则边变绿入选并触发并查集合并；若 $Find(u) == Find(v)$，则在画布上**短暂闪烁若加入该边将形成的环路**，随后将该边置灰标记为“成环丢弃”。
56. **Borůvka 算法 (多组件并发生长)**：
    * 每一轮中，每个连通分量（用不同底色气泡包裹）同时探测各自向外连接的最小权出边（Hook Edge），随后将所有选中的钩子边并发收缩合并，直观展示为什么最多只需 $O(\log V)$ 轮即可合并完毕。57. **严格/非严格次小生成树 (Second-Best MST)**：
    * 先求出 MST，再逐一尝试枚举每条非树边 $(u, v, w)$：加入 $(u, v)$ 后高亮树上唯一简单环，通过 LCA 路径查询找到环上最大权边 $w_{max}$（及严格小于 $w$ 的次大权边），实时计算替换差值 $\Delta = w - w_{max}$ 更新全局次小答案。
58. **有向图最小树形图：朱刘算法 (Chu-Liu / Edmonds' Algorithm)**：
    * 完整演示 4 个核心步骤：① 除根外每个点选最小入边（高亮选中弧） $\to$ ② 检测是否存在有向环（若无环则算法结束） $\to$ ③ **缩环动画（将有向环收缩为一个超级大节点，并动态重算所有进出该环的边权 $w' = w - w_{in}$）** $\to$ ④ 展开超级节点还原原图最小树形图。

#### 专题 G4：有向无环图与拓扑序算法 (DAG & Topological Algorithms)
59. **Kahn 算法 (基于入度的 BFS 拓扑排序)**：
    * 每个节点顶部实时显示入度徽章 `in-degree = k`（`k=0` 时徽章变绿）。
    * 每次从队列弹出一个 0 入度节点排入底部“拓扑序列槽”，并播放**擦除/淡化其所有出边、同时将目标节点入度 `-1` 的动画**。若队列为空但图中仍有剩余节点，自动高亮无法消除的环路死锁结构。
60. **基于 DFS 逆后序的拓扑排序**：记录每个节点递归退栈完成时间 `finish_time`，按完成时间从大到小逆序排列，对比后向边判环机制。
61. **AOE 网与关键路径算法 (Critical Path Method - CPM)**：
    * 第一遍正向拓扑递推：在每个事件节点左半区填入**事件最早发生时间 $ve[i]$**。
    * 第二遍逆向拓扑递推：在每个事件节点右半区填入**事件最迟发生时间 $vl[i]$**。
    * 计算每条活动边的 `[e, l, slack = l - e]`，将所有余量 `slack == 0` 的关键活动边用**金色双实线加粗高亮**，构成完整关键路径。

#### 专题 G5：连通性、双连通与强连通分量 (Connectivity & Component Decomposition)
62. **Tarjan 有向图强连通分量算法 (SCC)**：
    * 节点双角标实时更新 `[dfn, low]`；右侧严格区分**系统递归调用栈**与**Tarjan SCC 辅助栈（并高亮节点 `inStack` 状态）**。
    * 清晰区分树边递归回溯更新 `low[u] = min(low[u], low[v])` 与栈内后向边/横叉边更新 `low[u] = min(low[u], dfn[v])`。
    * 当回溯至某节点满足 `dfn[u] == low[u]` 时，触发**弹栈聚类动画：用彩色半透明凸包气泡包裹该 SCC 的所有节点**；算法结束时支持一键点击**“执行缩点（Contract to DAG）”**将每个气泡平滑收缩为超级节点并生成缩点 DAG。
63. **Kosaraju 强连通分量算法**：
    * 第一遍在原图 $G$ 上 DFS 求后序完成栈；随后播放**全图所有有向边箭头原地 180° 翻转变为反图 $G^T$ 的动画**；第二遍按逆后序在 $G^T$ 上 DFS 剥离强连通分量。
64. **无向图割点 (Articulation Points) 与桥/割边 (Bridges)**：
    * 实时验证割点判定法则（非根 $low[v] \ge dfn[u]$，根节点子树数 $\ge 2$）与桥判定法则（$low[v] > dfn[u]$）。
    * **交互式破坏测试**：算法完成后，允许学生鼠标点击任意高亮的割点或桥执行“临时拔除”，画布立即通过力导向排斥动画展示原图分裂为多个孤立连通块的效果！
65. **点双连通分量与圆方树构造 (v-BCC & Block-Cut / Round-Square Tree)**：
    * 演示栈维护点双连通分量，并在找到一个点双时**动态生成一个方形节点（Square Node ■）向该点双内所有原图圆点（Round Node ●）连边**，将复杂无向图平滑展开为一棵清晰的圆方树。
66. **边双连通分量 (e-BCC)**：演示切断所有桥边后，剩余各连通块缩点形成边双连通树的过程。
67. **2-SAT 布尔可满足性图解器**：
    * 输入形如 $(x_1 \lor \neg x_2) \land (\neg x_1 \lor x_3)$ 的逻辑子句，画布将每个变量拆分为上下对称的 $x_i$（真）与 $\neg x_i$（假）两个节点，自动绘制逆否成对蕴含边；随后运行 Tarjan 缩点，检验是否存在 $x_i$ 与 $\neg x_i$ 落入同一 SCC 的矛盾，或按反拓扑序为每个变量染上最终真/假颜色。

#### 专题 G6：网络流与最小割算法族 (Network Flow & Cuts)
68. **Ford-Fulkerson 与 Edmonds-Karp 最大流算法**：
    * 每条边显示胶囊标签 `flow / capacity`，边线粗细或内部流体填充比例随流量占比动态变化。
    * 每次 BFS 寻找到一条 $S \to T$ 增广路后，先闪烁整条路径并标出瓶颈残余容量 $\Delta = \min(c_f)$，随后播放**正向边流量增加 $+\Delta$、同时虚线反向退流边容量增加 $+\Delta$ 的同步动画**，顶部仪表盘累加总流量 `MaxFlow`。
69. **Dinic 最大流算法（分层图与阻塞流可视化）**：
    * **阶段一（BFS 分层）**：从源点 $S$ 运行 BFS 标注每个节点的层级 `level[u]`，**画布自动触发层次布局（或绘制垂直分层泳道背景线 Level 0, Level 1, Level 2...），并将非相邻层的无效边暂时半透明虚化**，只凸显满足 `level[v] == level[u] + 1` 的分层图骨架！
    * **阶段二（DFS 多路增广与当前弧优化）**：在分层图上运行 DFS 寻找阻塞流（Blocking Flow），在每个节点旁用小指针标记**当前弧 `cur[u]`**，已经榨干的分支边标记为灰色不再重复扫描。
70. **最高标号预流推进算法 (Push-Relabel / HLPP)**：
    * 打破增广路思维，采用极具直觉的**“水往低处流”物理隐喻可视化**：
    * 每个节点左侧显示**高度标尺徽章 `h[u]`**（源点初始抬高至 $h[S] = V$），右侧渲染一个**动态水位柱显示超额流 `excess e[u]`**。
    * 清晰演示两个原子动作：**`Push(u, v)`（当 $e[u] > 0$ 且存在满足 $h[u] == h[v] + 1$ 的残余边时，水流向低处节点）** 与 **`Relabel(u)`（当 $e[u] > 0$ 但周围邻居高度全都 $\ge h[u]$ 时，将节点 $u$ 的高度原地抬高至最低可推邻居高度 $+1$）**。
71. **最小割定理可视化 (Max-Flow Min-Cut Partition)**：
    * 在任意最大流算法结束后，点击“显示最小割”：系统自动从源点 $S$ 沿残量网络中剩余容量 $>0$ 的边进行可达性泛洪染色，将可达点集染为 $S$-集（蓝），不可达点集染为 $T$-集（橙），并**在画布上绘制一条横穿所有满流割边的红色锯齿切割线**，验证 $\text{Max Flow} == \text{Min Cut Capacity}$。
72. **最小费用最大流 (MCMF - SSP 连续最短路增广)**：
    * 边标签显示三元组 `flow / cap ($cost)`。
    * 每一轮在残量网络上以单位费用 `cost`（反向边费用为 `-cost`）作为边权，运行 SPFA 或带势函数（Potential）的 Primal-Dual Dijkstra 寻找**最小费用增广路**，实时更新顶部双仪表盘：`Total Flow` 与 `Total Cost`。

#### 专题 G7：二分图与图匹配算法 (Bipartite Graphs & Matching)
73. **二分图黑白染色判定法 (Bipartite Check & Odd Cycle Detection)**：
    * BFS/DFS 交替对相邻节点染蓝/橙两色；若合法则自动将节点平滑平移重组为左右双列二分图布局；若遇到同色相邻边，立即**高亮由该冲突边构成的奇数长度环（Odd Cycle）**并给出不可二分结论。
74. **匈牙利算法 (Hungarian / Kuhn 二分图最大匹配)**：
    * 匹配边用加粗粉红实线表示，非匹配边用细灰线表示。
    * 重点演示“腾位置（交错路增广）”过程：从左部未匹配点出发走“非匹配边 $\to$ 匹配边 $\to$ 非匹配边...”形成交错路（Alternating Path），当到达右部未匹配点时，**播放整条交错路所有边状态取反（非匹配变匹配、原匹配解绑）的翻转动画**，匹配数 $+1$。
75. **带权二分图最佳完美匹配：KM 算法 (Kuhn-Munkres)**：
    * 左部节点显示顶标 `lx[i]`，右部节点显示顶标 `ly[j]`。
    * **严格区分“相等子图边（满足 `lx[i] + ly[j] == w(i,j)`，用亮色实线绘制）”与“非相等子图边（虚线半透明，标出差值 `slack`）”**。
    * 当匈牙利 DFS 在相等子图中增广受阻时，高亮交错树集合 $S$ 与 $T$，计算最小松弛量 $d = \min \{ lx[i] + ly[j] - w(i,j) \}$，并播放 **$S$ 中左顶标全部 $-d$、$T$ 中右顶标全部 $+d$、从而将一条新虚线边拉入相等子图变成实线边** 的核心教学过程！76. **一般图最大匹配：带花树算法 (Edmonds' Blossom Algorithm)**：
    * 在非二分图上构建交错树，对节点染偶点（Outer/蓝）与奇点（Inner/橙）。
    * 当偶点之间连边发现奇环（Blossom，“花”）时，**播放将整个奇环上的节点聚拢收缩为一朵“花朵超级节点（✿）”的动画**，在缩花后的图上继续寻找增广路，找到后再将花朵逐层展开还原匹配边。

#### 专题 G8：欧拉图、哈密顿图与经典进阶图算法 (Eulerian, Routing & Advanced)
77. **欧拉路径与欧拉回路：Hierholzer 算法**：
    * 预检所有节点的度数（无向图奇度点个数，有向图入度与出度差），高亮合法的起点与终点。
    * 演示 Hierholzer 深度优先走边删边：当走到死胡同时将节点逆序压入结果栈，遇到仍有剩余出边的分叉点时**自动探出子环路并无缝嵌入主环路**的拼合过程。
78. **图顶点着色与最大团 (Graph Coloring & Bron-Kerbosch Maximal Clique)**：
    * 图着色：演示回溯法 $m$-着色试错与 Welsh-Powell / DSatur 饱和度启发式贪心着色。
    * 最大团：同步展示 Bron-Kerbosch 算法的三个核心集合 `R（当前团）`、`P（候选集）`、`X（已排除集）` 随递归与枢轴（Pivot）剪枝的动态演变。

### 4.2 必备原子渲染指令集 (Atomic Visual Operations)
渲染引擎必须实现以下 12 类原子指令的平滑动画解析与**逆向回退（Undo/Reverse）**：
1. `SET_NODE_STATE` / `SET_EDGE_STATE`：切换节点或边的语义状态与配色。
2. `UPDATE_NODE_BADGE` / `UPDATE_EDGE_LABEL`：更新角标数值或边标签（如 `flow/cap`），并触发微缩放高亮动画。
3. `UPDATE_NODE_SLOTS`：专用于 B 树 / 2-3-4 树 / 线段树，更新多槽位节点内部的键值数组 `[k1, k2, ...]`。
4. `TRAVERSE_EDGE_PULSE`：沿指定有向/无向边从起点向终点（或逆向）发射高光脉冲粒子。
5. `MORPH_LAYOUT`：传入新的节点目标坐标字典 `{ nodeId: {x, y} }`，在指定毫秒内使用缓动函数平滑移动所有节点及连线（用于树旋转、分裂、DSU 路径压缩、缩点）。
6. `DRAW_TEMP_ARC` / `CLEAR_TEMP_ARC`：绘制临时彩色虚线弧（用于 Morris 线索指针、旋转前预示新父子关系、AC 自动机 `fail` 指针、倍增 LCA 跳跃轨迹）。
7. `GROUP_NODES_HULL` / `CONTRACT_GROUP`：用半透明凸包气泡包裹一组节点（用于 SCC、双连通分量、Borůvka 连通块、带花树奇环），或将该组节点平滑收缩为一个超级节点。
8. `DRAW_CUT_LINE`：在两组节点集合之间绘制最小割或 Prim 切分虚线。
9. `AUX_CONTAINER_OP`：操作右侧辅助队列、双端队列、栈、优先队列的 `push / pop / front_push / reorder`。
10. `AUX_TABLE_UPDATE` / `AUX_MATRIX_UPDATE`：更新状态追踪表或 Floyd 二维矩阵单元格并触发闪烁。
11. `AUX_DSU_SYNC`：同步更新右下角并查集副视图的父指针树。
12. `AUX_ARRAY_SYNC`：同步更新底部一维紧凑数组条（用于堆、树状数组、DFS 序区间）。
